IntentCategories

interface IntentCategories

Intent 类别接口，定义了 Android Intent 中常用的 CATEGORY 常量。 类别提供了关于要执行的操作的额外信息（例如：这是一个启动器 Activity，或者这应该在浏览器中打开）。
