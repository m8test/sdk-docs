interface LocalMcpServer : McpServer, ToolRegistry

M8Test默认启动的本地Mcp服务器接口，定义了本地Mcp服务器的操作。

该接口继承自 McpServer 和 ToolRegistry 接口，可进行工具的注册和注销操作， 同时具备Mcp服务器的基本功能。
