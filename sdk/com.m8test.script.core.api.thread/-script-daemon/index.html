ScriptDaemon

interface ScriptDaemon : ScriptCloseable

一个 ScriptThread 对应多个 ScriptDaemon,一个 ScriptDaemon 只能属于一个 ScriptThread.

当 ScriptThread 没有 android.os.Handler 的消息以及所有 ScriptDaemon 都结束之后才能结束.
