Task

interface Task

定时任务 Timer 中执行的任务单元，封装了任务的基本信息和参数。

每个任务实例包含唯一标识、类型信息和执行参数，用于在定时器中进行任务管理和执行。 实现类需提供参数的存取逻辑、任务ID和类型的定义。
