WebSocketServerSession

interface WebSocketServerSession : WebSocketSession

代表一个由 HTTP 服务器接受的 WebSocket 会话。

这是一个标记接口，继承自通用的 WebSocketSession，用于明确表示这是一个服务器侧的连接。
