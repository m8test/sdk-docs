HttpServerRequest

interface HttpServerRequest

封装了从客户端接收到的一个 HTTP 请求的所有信息。

在服务器的请求处理逻辑中，你可以通过 HttpServerCall.getRequest 访问此对象， 以获取 URL、头部、查询参数、请求体等所有相关数据。
