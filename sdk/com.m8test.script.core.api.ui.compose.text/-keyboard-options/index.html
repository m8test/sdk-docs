用于配置软键盘外观和行为的接口。

通过此接口，可以自定义键盘的类型、自动大写规则、自动纠错功能、 以及在键盘上显示的“操作”按钮（例如“完成”或“下一步”）。 它包装了 androidx.compose.foundation.text.KeyboardOptions，为自动化脚本提供了一种声明式配置键盘选项的方式。
