Sqlite

interface Sqlite : ScriptCloseable

Sqlite 数据库接口，提供原生 SQL 语句的执行与查询功能。

该接口封装了对 SQLite 数据库的操作，允许执行非查询语句（如 CREATE, INSERT, UPDATE, DELETE） 以及查询语句（SELECT），并将查询结果以易于处理的集合形式返回。 同时支持简单的事务管理与数据库连接关闭操作。
