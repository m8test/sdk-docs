getExternalFilesDir

abstract fun getExternalFilesDir(type: String?): String?

返回所有共享/外部存储设备上特定于应用程序的目录的绝对路径, 应用程序可以在其中放置其拥有的持久文件.

这些文件对于应用程序来说是内部的, 并且通常对用户不可见. 当应用被卸载时, 这些目录及其内容会被清除.

Return

特定于应用程序的目录的绝对路径. 如果共享存储当前不可用或发生错误, 则可能返回 null.

Parameters

type

要返回的文件目录的类型. 如果为 null, 则返回应用专属文件的根目录; 否则, 返回根目录下的指定子目录 (例如 Environment.DIRECTORY_PICTURES).
