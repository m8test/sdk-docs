ScriptCloseable

interface ScriptCloseable : ScriptContextual, Closeable

当脚本中的使用到的类需要在脚本退出时自动回收资源时可以实现本接口, 如果实现了本接口的对象没有被调用 close 方法就会报错.

由于不能直接实现本接口, 所以将其叫标记为 Internal, 防止外界直接实现本接口.
