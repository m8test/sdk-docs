unregisterTool

fun unregisterTool(origin: Any, tool: Tool): Result

从 Model Context Protocol(MCP) 系统注销一个工具，并关联发起注销的来源对象。

工具注销遵循引用计数规则：只有当所有注册该工具的 origin 都调用此方法后， 工具才会被真正从系统中注销。

Return

注销结果，包含操作状态和可能的错误信息

Parameters

origin

发起注销的对象，必须与注册时的 origin 一致

tool

需要注销的工具实例
