create

fun create(origin: Any, config: Config.() -> Unit): Display

根据指定配置创建一个新的虚拟屏幕，并将其与一个 origin 对象关联起来以进行生命周期管理。

创建成功后，这个新的虚拟屏幕会被自动注册。当 origin 生命周期结束时，该屏幕将被自动销毁。

Return

新创建的 Display 实例。

Parameters

origin

发起创建操作的源对象，通常是脚本上下文或管理器。用于后续的资源清理。

config

一个类型安全的配置闭包，用于定制新屏幕的各项参数（如分辨率、DPI等）。
