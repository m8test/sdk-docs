FlowCollector (流收集器) 是 Flow 的中间或终端操作符，它代表一个可以接收 Flow 所发出值的实体。

您通常不需要直接实现这个接口，而是通过函数式（SAM）转换来使用它， 例如在 flow.collect { ... } 的 lambda 块中，您所在的上下文就是一个 FlowCollector。

此接口的实现不是线程安全的。
