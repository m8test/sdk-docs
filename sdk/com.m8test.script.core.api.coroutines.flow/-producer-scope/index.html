ProducerScope

interface ProducerScope<T> : CoroutineScope, SendChannel<T>

一个用于从多值回调或监听器 API 创建 Flow 的生产者接口。

当你调用 Flows.fromCallback 时，你会得到这个接口的实例。它本身就是一个 CoroutineScope， 允许你在其上下文中启动新的协程来处理事件和发送数据。
