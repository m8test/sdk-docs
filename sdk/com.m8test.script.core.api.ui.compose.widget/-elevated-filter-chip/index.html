ElevatedFilterChip

interface ElevatedFilterChip<T : Modifier> : FilterChip<T>

表示一个 Material Design 浮动筛选小纸条 (Elevated Filter Chip) 的属性。

小纸条可帮助用户输入信息、进行选择、筛选内容或触发操作。 筛选小纸条使用标签或描述性词语来筛选内容，可以作为切换按钮或复选框的良好替代品。 此筛选小纸条应用了浮动样式，与扁平样式的 FilterChip 相比具有阴影效果。 点按筛选小纸条会切换其选择状态。
