JsonObject

interface JsonObject : JsonElement

表示 JSON 规范中的对象 ({})。

JsonObject 是一个从字符串键到 JsonElement 值的无序映射。 这是一个可变对象，可以在创建后自由地添加、修改或删除其属性。
