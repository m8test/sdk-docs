Device

interface Device : Variable

设备信息与操作接口。

提供对安卓设备硬件信息、系统状态、存储空间、网络状态的只读访问， 震动控制等交互功能。

注意：部分方法在 Android 高版本（如 Android 10+）上可能受系统隐私策略限制， 无法获取真实数据（如 Serial, MacAddress），文档中已对相应方法做出说明。
