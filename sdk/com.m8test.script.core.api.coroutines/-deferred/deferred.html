deferred

abstract fun <R> deferred(handler: (CoroutineScope, T) -> Deferred<R>): Deferred<R>

将一个 返回 Deferred 的异步函数链接到当前 Deferred 的成功结果上，并返回一个新的 Deferred。

与 then 的区别在于：

  • then 要求 handler 同步 返回 R 或 隐式展开 另一个 Deferred<R>；

  • deferred 要求 handler 显式 返回 Deferred<R>，框架会自动等待该 Deferred 完成， 并将最终结果作为新 Deferred 的计算结果。

典型用途：在链式调用中需要 显式启动另一个异步任务（如网络请求、数据库查询等）， 并希望保持链式语法、避免嵌套回调。

示例：

fetchUser(userId)               // Deferred<User>
    .deferred { user -> fetchUserPosts(user.id) } // Deferred<List<Post>>
    .then { posts -> render(posts) }
