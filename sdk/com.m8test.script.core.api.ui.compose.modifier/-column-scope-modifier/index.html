ColumnScopeModifier

interface ColumnScopeModifier : ScopeModifier<ERROR CLASS: Symbol not found for ColumnScope>

一个专为 Column 布局的子组件设计的 Modifier 作用域。

它提供了在 Column 内部控制子组件垂直权重和水平对齐方式的方法。
