ScrollState

interface ScrollState : ScrollableState

一个可以被提升（hoisted）的状态对象，用于控制和观察可滚动组件（如 verticalScroll/horizontalScroll）的滚动。

这个对象通常是通过 com.m8test.script.core.api.ui.compose.slot.Slot.newScrollState 创建的。
