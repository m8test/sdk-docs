LazyListState

interface LazyListState : ScrollableState

一个可以被提升（hoisted）的状态对象，用于控制和观察惰性列表（LazyList）的滚动。

在大多数情况下，这个对象是通过 com.m8test.script.core.api.ui.compose.slot.Slot.newLazyListState 创建的。
