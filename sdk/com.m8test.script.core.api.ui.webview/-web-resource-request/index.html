WebResourceRequest

interface WebResourceRequest : ObjectWrapper<WebResourceRequest>

封装并提供对WebView资源请求的详细访问。

此接口包含了请求的URL、方法、头信息以及请求上下文（如是否为主框架请求）等关键数据。
