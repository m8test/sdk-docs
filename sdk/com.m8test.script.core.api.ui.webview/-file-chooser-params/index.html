FileChooserParams

interface FileChooserParams

代表文件选择器请求的参数，该请求由 WebView 的 onShowFileChooser 方法触发。

此接口提供了有关文件请求的详细信息，例如选择模式、可接受的 MIME 类型、 是否启用了媒体捕获等。其设计参考了 Android 的 android.webkit.WebChromeClient.FileChooserParams 类。
