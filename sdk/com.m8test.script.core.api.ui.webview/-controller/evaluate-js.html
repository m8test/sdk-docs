evaluateJs

abstract fun evaluateJs(url: String, repeatable: Boolean): String?

加载并执行网络中的JavaScript文件，并同步等待其执行结果。

Return

脚本最后一条语句的执行结果，以字符串形式返回。如果脚本没有返回值或执行失败，则结果为null。

Parameters

url

JS文件的网络URL地址。

repeatable

是否允许重复执行：true表示同一URL可多次执行，false表示仅首次执行有效。

Throws

TimeoutException

如果脚本执行超时。

IllegalStateException

如果无法发起执行请求（如URL无效）。
