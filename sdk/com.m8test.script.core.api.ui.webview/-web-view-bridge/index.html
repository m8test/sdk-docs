WebViewBridge

interface WebViewBridge

提供脚本与网页端交互的桥接接口，支持注册原生方法供JS调用、调用JS函数及执行JS代码等功能。

该接口封装了WebView与JavaScript之间的通信能力，允许原生代码与网页端进行双向数据交互， 适用于需要通过脚本控制网页行为或接收网页事件的场景。
