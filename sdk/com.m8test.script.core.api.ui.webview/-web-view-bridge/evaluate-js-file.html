evaluateJsFile

abstract fun evaluateJsFile(file: ScriptFile, repeatable: Boolean, callback: (String?) -> Unit?): Result

执行本地存储的JavaScript文件。

从ScriptFile指定的本地文件中读取JS内容并在WebView中执行，适用于预打包的本地脚本。

Return

Result 执行结果：成功读取并执行文件时包含true，失败时包含false（如文件不存在或不可读）

Parameters

file

包含JS内容的本地文件对象

repeatable

是否允许重复执行：true表示可多次执行同一文件，false表示仅首次执行有效

callback

执行完成后的回调：参数为JS执行结果（可为null，如无返回值或执行失败）
