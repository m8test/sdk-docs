DisposableEffect

interface DisposableEffect

DisposableEffect 用于封装 Jetpack Compose 的 DisposableEffect。 它用于处理那些需要在 Composable 离开组合或其 key 发生变化时进行清理的附带效应。

当 keys 中的任何一个值发生变化时，当前的效应会被清理（通过调用 onDispose），然后重新执行新的效应。 这对于订阅外部数据源或管理需要明确释放的资源非常有用。
